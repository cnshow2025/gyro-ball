# 星際鋼珠 · 陀螺儀闖關

用手機的陀螺儀（重力感應）控制 3D 軌道的傾斜，讓金屬鋼珠沿著軌道滾進傳送門。純網頁製作，不需要安裝 App。

## 玩法
- 傾斜手機，鋼珠就會往低處滾動；倒數結束時，當下的握持角度會被當作「水平」。
- 收集每關 3 顆 **晶石**，每顆可折抵 2 秒成績。
- 掉出軌道會回到起點，或回到最近的 **檢查點**（地上的光圈）。
- 滾進 **傳送門** 就通關，並解鎖下一關。
- 右上角 ⊕ 可隨時重新校正水平，❚❚ 可暫停。
- 電腦上可用方向鍵 / WASD，或在畫面上拖曳滑鼠來測試。

## 關卡
1. 啟航：寬敞木軌
2. 雙峰：上下坡
3. 浮動橋：移動平台
4. 旋轉閘門：旋轉掃桿與窄道
5. 星際迴廊：所有機關的綜合挑戰

## 功能
- 3D 畫面（Three.js）＋物理引擎（cannon-es）
- 計時排行榜（每關前 10 名，存在手機本機）
- 音效（即時合成）與震動回饋（iPhone Safari 不支援網頁震動）
- 可加入主畫面，以全螢幕方式遊玩

## 技術
- 純靜態網頁：`index.html`、`style.css`、`js/`
- 函式庫已放在 `vendor/`（three.js r186、cannon-es 0.20），不依賴外部 CDN
- 陀螺儀需要 **HTTPS**，GitHub Pages 本身就是 HTTPS

## 部署（GitHub Pages）
Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → Save。
一兩分鐘後即可從 `https://cnshow2025.github.io/gyro-ball/` 開始遊玩。
