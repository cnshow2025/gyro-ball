# 星際鋼珠 · 陀螺儀闖關

橫拿手機，像玩迷宮板一樣傾斜，帶金屬鋼珠走完遊樂園裡的木造雲霄飛車軌道，衝過終點拱門。純網頁製作，不需要安裝 App。

## 玩法
- **橫向畫面**：倒數時先看整關全貌，開始後鏡頭拉近跟著鋼珠（角度固定，操控方向不變）。
- 軌道有上下起伏：借下坡的衝力衝上山頂；凹谷坡度平緩，慢慢傾斜也爬得出來。
- **像迷宮板一樣傾斜**：手機往哪邊傾，整塊板子就往哪邊低，鋼珠往畫面上那個方向滾。
  - 左右傾 → 往畫面左右滾；前後傾 → 往畫面上下滾。
  - 軌道轉彎後要換個方向傾，珠子才會繼續前進。
- 倒數結束時，當下的握持角度會被當作「水平」；右上角 ⊕ 可重新校正。
- 收集 **晶石**，每顆可折抵 2 秒成績。
- 掉下去會回到起點，或最近通過的 **檢查點**（軌道上的光環）。
- 衝過 **終點拱門** 就通關，並解鎖下一關。

## 機關
- **小間隙**：軌道缺口（兩端枕木是橘色），有點速度就能跨過去。
- **旋轉轉盤**：橘色圓盤上的一段軌道，一格一格轉動；對齊時滾上去，轉到出口後再滾出來。
- **旋轉掃桿**：紅色桿子掃過軌道，被打到會飛出去；等它掃過再衝。
- **移動橋／升降台**：一段會左右滑動或上下升降的軌道（淡橘色方塊是它的移動範圍）；對齊時才能通過。

## 關卡
1. 入門迴廊　2. 階梯瀑布　3. 小小缺口　4. 旋轉掃桿
5. 移動橋　6. 旋轉轉盤　7. 機關組合　8. 星際迴廊
9. 過山車　10. 起伏缺口　11. 高低落差　12. 終極大冒險

## 功能
- 3D 畫面（Three.js）：木板路面、木護欄、白色木格子支架、草地模型台與遊樂園場景
- 自製沿軌道物理（接軌、飛越、落軌、被撞飛）
- 計時排行榜（每關前 10 名，存在手機本機）
- 音效（即時合成）與震動回饋（iPhone Safari 不支援網頁震動）
- 設定可調傾斜靈敏度；可加入主畫面全螢幕遊玩

## 技術
- 純靜態網頁：`index.html`、`style.css`、`js/`
- 函式庫已放在 `vendor/`（three.js r186），不依賴外部 CDN
- 關卡用 `js/levels.js` 的畫筆描述（straight、turn、hill、dip、gap、turntable、bridge、sweeper），新增關卡很容易
- 陀螺儀需要 **HTTPS**，GitHub Pages 本身就是 HTTPS

## 部署（GitHub Pages）
Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → Save。
一兩分鐘後即可從 `https://cnshow2025.github.io/gyro-ball/` 開始遊玩。
