# 星際鋼珠 · 陀螺儀闖關

用手機的陀螺儀（重力感應）控制重力方向，讓金屬鋼珠在雲霄飛車雙軌上一路衝進傳送門。純網頁製作，不需要安裝 App。

## 玩法
- **純重力操控**：手機往前傾＝前方變下坡，鋼珠加速；往後傾＝變上坡，鋼珠減速。
- 左右傾會讓鋼珠往一側偏；彎道太快會被離心力往外甩，要往彎道內側傾來平衡。
- 山頂太快會騰空、彎道太快會被甩出軌道；畫面邊緣閃紅光表示快要飛出去了。
- **斷橋**：前方枕木變橘色代表斷橋，要衝夠快才飛得過去、接回對面軌道。
- 倒數結束時，當下的握持角度會被當作「水平」。
- 收集沿途的 **晶石**，每顆可折抵 2 秒成績。
- 飛出軌道會回到起點，或最近通過的 **檢查點**（軌道上的光環）。
- 穿過終點 **傳送門** 就通關，並解鎖下一關。
- 右上角 ⊕ 可隨時重新校正水平，❚❚ 可暫停。
- 電腦上可用方向鍵 / WASD，或在畫面上拖曳滑鼠來測試。

## 關卡
1. 啟航：緩坡與大彎道
2. 波浪：連續山丘，太快會騰空
3. 飛躍斷橋：第一次飛越斷橋
4. 急彎連橋：髮夾彎接連續斷橋
5. 星際迴廊：高空俯衝、垂直迴圈、螺旋與斷橋

## 功能
- 3D 畫面（Three.js）＋自製沿軌道物理（貼軌、騰空、甩出、飛越後重新接軌）
- 計時排行榜（每關前 10 名，存在手機本機）
- 音效（即時合成）與震動回饋（iPhone Safari 不支援網頁震動）
- 可加入主畫面，以全螢幕方式遊玩

## 技術
- 純靜態網頁：`index.html`、`style.css`、`js/`
- 函式庫已放在 `vendor/`（three.js r186），不依賴外部 CDN
- 關卡用 `js/levels.js` 的路徑畫筆描述（直線、彎道、山丘、跳台、斷橋、迴圈），新增關卡很容易
- 陀螺儀需要 **HTTPS**，GitHub Pages 本身就是 HTTPS

## 部署（GitHub Pages）
Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → Save。
一兩分鐘後即可從 `https://cnshow2025.github.io/gyro-ball/` 開始遊玩。
